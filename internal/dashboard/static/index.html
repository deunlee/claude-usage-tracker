동작 방식

수집 주기
2분마다 확인합니다. 3회 연속 변화가 없으면 5분, 이어서 6회 연속 변화가 없으면 10분 간격으로 늘립니다. 5시간·주간 사용률이 바뀌면 바로 2분으로 돌아갑니다.
지금 수집
위쪽 새로고침 버튼을 누르면 모든 계정을 마지막 수집 2분 뒤에 바로 수집하고, 5분·10분 주기였다면 2분으로 되돌립니다. 한도에 닿아 30분 주기일 때는 그 한 번만 앞당깁니다. 요청 보류(429) 중에는 보류가 끝난 뒤에 수집합니다.
초기화 전후
5시간·주간 창이 초기화되기 2분 전과 직후에 한 번씩 더 기록합니다. 그래서 그래프가 초기화 시각에 바로 떨어집니다. 초기화 2분 전 기록부터 수집 주기를 2분으로 되돌립니다.
한도 도달
5시간 또는 주간(모든 모델) 한도가 100%면 초기화될 때까지 값이 움직이지 않으므로 30분마다 수집합니다. 초기화 전후 기록은 그대로 남깁니다. Fable 같은 모델별 주간 한도는 100%가 돼도 주기를 바꾸지 않습니다.
토큰 만료
아래 명령으로 Claude Code를 한 번 실행해 토큰을 갱신합니다. claude -p hello --model haiku --no-session-persistence --setting-sources user --strict-mcp-config 세션 기록은 남기지 않지만 사용량은 조금 씁니다. 실패하면 10분 뒤 다시 시도합니다.
요청 제한 (429)
응답이 알려 준 시간만큼 기다린 뒤 다시 요청합니다. 최대 1시간까지 기다립니다.
여러 계정
~/.claude와 config.json의 extraClaudeConfigDirs에 적은 디렉터리를 계정마다 따로 수집합니다. 위의 주기·보류·토큰 갱신도 계정마다 따로 돌고, 그래프에 쓰는 기록은 archive/<이메일>/에, 받은 응답 전체는 logs/에 쌓입니다.
다시 시작
꺼져 있는 동안 5시간·주간·모델별 주간(Fable 등) 창이 초기화됐으면, 마지막으로 받은 응답의 초기화 시각 1초 전에는 마지막 값을, 초기화 시각에는 0%를 그래프에 기록해 그 시각에 바로 떨어지게 하고 수집을 시작합니다.
